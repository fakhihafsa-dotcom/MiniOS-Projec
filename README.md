مشروع نظام التشغيل المصغر - MiniOS 

هذا المستودع يحتوي على الهيكلية الكاملة والتطبيق العملي لنواة نظام تشغيل مصغر (MiniOS) يدعم معيار الإقلاع المتعدد (Multiboot Specification) لإدارة العمليات، الذاكرة، والمقاطعات.

هيكلية ملفات النواة (Kernel Architecture)
تم تقسيم النواة إلى وحدات برمجية منفصلة لضمان الكفاءة وتنظيم المكونات:

* **النواة الأساسية:** `kernel.cpp` (نقطة الدخول للنظام بعد الإقلاع `kmain`).
* **إدارة العمليات والجدولة:** `scheduler.cpp` / `scheduler.h` (جدولة المهام وتوزيع الأولويات).
* **إدارة الذاكرة:** `memory.cpp` / `memory.h` (إعداد وتخصيص الذاكرة الفيزيائية).
* **المقاطعات والعتاد:** `interrupts.cpp` / `interrupts.h` و `pic.cpp` / `pic.h` (التحكم في إشارات العتاد ولوحة المفاتيح).
* **بروتوكولات الإدخال والإخراج:** `portio.cpp` / `portio.h` و `keyboard.cpp` / `keyboard.h`.
* **واجهة العرض ولوحة التحكم:** `vga.cpp` / `vga.h` و `dashboard.cpp` / `dashboard.h` (إدارة الشاشة والواجهة التفاعلية).
* **المكتبات المساعدة:** `math.cpp` / `math.h` و `ktypes.h`.

 آلية الإقلاع والتشغيل
يعتمد النظام على مواصفات **Multiboot** بحيث يتولى محمل الإقلاع القياسي تهيئة المعالج ونقل التحكم مباشرة إلى الدالة الرئيسية `kmain` المكتوبة بلغة C++ لبدء تشغيل لوحة التحكم والمجَدول.
